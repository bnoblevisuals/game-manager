# Game Manager

Game Manager is a full-stack project management and production tracking application designed for game development teams.

The goal is to provide a centralized place for teams to organize projects, track tasks, manage production progress, and collaborate throughout game development.

## Tech Stack

- Java
- Spring Boot
- PostgreSQL
- React
- JavaScript
- Git / GitHub

## Project Status

Currently in development.

This project is being built incrementally, beginning with the core application architecture and database foundation.
